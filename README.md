# Cherry Studio 主题 · Claude × DeepSeek

给 [Cherry Studio](https://github.com/CherryHQ/cherry-studio) 用的自定义 CSS 主题：深色玻璃 + 橙色高光，壁纸内嵌，不依赖任何本地文件。

只有一套。Claude 娘和 DeepSeek 大肥鱼都画在同一张背景图里，所以名字叫 Claude × DeepSeek。

说句实话，这套配色真的很好看。

## 笔记本用户注意（重要）

**如果你要的是真毛玻璃，请做好被电流声折磨的准备。**

毛玻璃不是免费的。它要显卡实时计算背景模糊，只要窗口开着、鼠标一动，显卡就在持续工作。

- 用独显跑：画面好看，但很多笔记本的供电模块会发出滋滋的电流声，安静环境里非常明显
- 切到核显跑：核显会被直接拉满，滚动和拖动窗口开始卡
- 想彻底没声音：只能把 `backdrop-filter` 全部删掉，那样也就没有毛玻璃了

台式机、或者不在乎噪音的机器，可以放心用。笔记本用户，慎重。

## 效果

- 深色毛玻璃：侧栏、输入框、菜单、弹窗
- 壁纸铺满全屏，左侧压暗保证文字可读
- Tooltip 深底白字
- 输入框淡玻璃 + 橙色描边
- 资料预览、代码块、表格统一深色

## 安装

1. 打开 Cherry Studio → 设置 → 显示 → 自定义 CSS
2. 打开 `cherry-claude-theme.css`，全选复制
3. 粘贴进设置里的输入框，保存
4. 从托盘退出 Cherry Studio 再重新打开

## 说明

- 壁纸以 base64 内嵌在 CSS 里，文件约 1MB，属正常
- 主题里的毛玻璃（`backdrop-filter`）会占用显卡，详见上面的「笔记本用户注意」
- 只适配浅色模式关闭、即深色模式下的 Cherry Studio
